Make a top-down arena shooter in the browser using Phaser 3 loaded from a CDN script tag (https://cdn.jsdelivr.net/npm/phaser@3.80.1/dist/phaser.min.js), no build step. Put it in index.html and game.js in the current directory.

The player moves with the keyboard and aims and shoots with the mouse. Enemies spawn from the edges in increasing numbers and chase the player. Shooting an enemy scores a point; touching one ends the game. Add simple sound effects with the Web Audio API (synthesised beeps are fine, no audio files). Use simple shapes for art.
